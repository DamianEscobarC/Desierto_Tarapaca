Desierto Tarapacá
1. Ficha del proyecto
Nombre de la aplicación: Desierto Tarapacá
Asignatura: Programación Android
Institución: Instituto Profesional Santo Tomás
Sede: Iquique
Docente: Leopoldo Rodríguez

Descripción
Desierto Tarapacá es una aplicación móvil Android orientada a optimizar la gestión de servicios sanitarios en terreno, incluyendo el arriendo y mantenimiento de baños químicos y la limpieza de fosas.
Su propósito es digitalizar el registro de información y facilitar la administración de las operaciones realizadas.

Objetivos
• Automatizar el registro diario de servicios en terreno.
• Permitir el almacenamiento local de información sin conexión a internet.
• Gestionar clientes y registrar ubicaciones GPS.
• Administrar el inventario de insumos químicos.
• Generar reportes de las operaciones realizadas.

2. Stack tecnológico
Las tecnologías utilizadas para el desarrollo de Desierto Tarapacá son las siguientes:

• Java: lenguaje de programación utilizado para desarrollar la lógica y las funcionalidades de la aplicación.
• Android Studio: entorno de desarrollo utilizado para crear, ejecutar y probar la aplicación.
• XML: utilizado para diseñar las interfaces gráficas de las diferentes pantallas.
• SQLite: base de datos local utilizada para almacenar la información de usuarios, clientes, servicios e inventario.
• MapLibre: herramienta utilizada para visualizar mapas y ubicaciones geográficas.
• GPS: permite obtener y registrar las ubicaciones geográficas del dispositivo.
• Git y GitHub: herramientas utilizadas para el control de versiones y almacenamiento del código fuente.

4. Guía de instalación y uso
Requisitos

• Android Studio.
• Dispositivo Android o emulador.
• Conexión a internet para descargar las dependencias iniciales.

Instalación
1. Descargar o clonar el repositorio desde GitHub:
https://github.com/DamianEscobarC/Desierto_Tarapaca
2. Abrir el proyecto en Android Studio.
3. Esperar a que Gradle sincronice las dependencias.
4. Seleccionar un dispositivo Android o emulador.
5. Ejecutar la aplicación mediante el botón Run.
   
Uso de la aplicación
1.Iniciar sesión o registrar una cuenta.
2.Acceder al menú principal.
3.Registrar tareas y servicios realizados en terreno.
4.Consultar y administrar los clientes.
5.Registrar ubicaciones mediante GPS.
6.Gestionar el inventario de insumos químicos.
7.
Generar reportes en formato Excel.
8.
Consultar la información de la cuenta y cerrar sesión.
